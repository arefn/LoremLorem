# Lorem Lorem

> A tiny, private, offline lorem-ipsum generator.
> Everything happens in your browser — nothing ever leaves it.

**🔗 Live:** <https://arefnorouzzadeh.github.io/LoremLorem/>

## Why “Lorem Lorem”?

Because once is never enough when you're filling in a design. Lorem Lorem is a
single HTML file that generates placeholder text in six flavors, copies it in one
click, and phones home to absolutely no one.

## Features

- **Six languages** — classic Latin (`lorem ipsum…`), Español, Français, Deutsch,
  Português, and فارسی (Persian) with full right-to-left rendering
- **Five output shapes** — paragraphs, sentences, words, bullet lists, and
  byte-exact chunks (UTF-8 aware, so Persian counts correctly)
- **Classic opening** — every language has its own canonical first sentence
- **HTML mode** — wraps paragraphs in `<p>`, lists in `<ul>/<li>`
- **Copy-first UX** — one-click copy, click-anywhere-to-select-all,
  `C` copies, `R` re-rolls
- **Editorial design** — paper texture, drop caps, dark & light themes,
  an amount slider synced with the stepper
- **Dark & light themes**, remembered locally
- **Fast & featherweight** — one file, zero frameworks, zero build step

## Privacy first 🔒

- All text is generated by a few lines of vanilla JavaScript **on your machine**
- **No tracking, no cookies, no analytics, no accounts, no server** — there is no
  backend at all
- The only external references are two *optional* webfonts (Fraunces from Google
  Fonts, Vazirmatn for Persian via jsDelivr). Block them or go offline and
  everything still works — the app falls back to system fonts
- One `localStorage` key remembers your theme preference. Delete it and even
  that is gone

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `C` | Copy the generated text |
| `R` | Generate a fresh batch |

## Run it locally

It's one static file — just open `index.html` in a browser, or serve it:

```sh
python3 -m http.server
# → http://localhost:8000
```

Deploying anywhere (GitHub Pages, Netlify, any static host) works as-is:
everything lives in the repo root, no build step, no config.
